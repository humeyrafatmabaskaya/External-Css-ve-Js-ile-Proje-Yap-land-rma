Türk Halk Masalları

Proje Hakkında
Bu proje, Türk halk anlatı geleneğinden seçilen sekiz masalı bir araya getiren bir web sitesidir. Kullanıcılar ana sayfada masalların illüstrasyonlarını, kısa özetlerini ve temalarını inceleyebilir; istedikleri masalın tam metnini okuyabilirler. Masallar arasında önceki ve sonraki düğmeleriyle geçiş yapılabilir. Okuma sırasında yazı boyutu büyütülebilir, küçültülebilir veya varsayılan boyuta döndürülebilir. Site telefon, tablet ve bilgisayarlara uyumludur.
Vize projesinde tek HTML dosyası içinde yer alan CSS ve JavaScript kodları, ayrı dosyalara taşınmıştır. Mevcut tasarım ve içerikler korunmuştur.
Proje Dosyalarının Yapısı
Turk-Halk-Masallari/
index.html   # Sayfanın HTML yapısı
style.css    # Harici CSS dosyası
script.js    # Harici JavaScript kodları, masal metinleri ve görseller
README.md    # Proje açıklaması ve çalıştırma bilgileri
index.html dosyasında CSS ve JavaScript dosyaları aşağıdaki şekilde bağlanmıştır:
<link rel="stylesheet" href="style.css">
<script src="script.js"></script>
Projeyi Çalıştırma
1. Proje dosyalarını indirin.
2. index.html, style.css ve script.js dosyalarının aynı klasörde olduğundan emin olun.
3. index.html dosyasına çift tıklayarak Chrome, Edge veya Firefox gibi bir web tarayıcısında açın.
Projeyi çalıştırmak için ek bir kurulum veya internet bağlantısı gerekmez.
